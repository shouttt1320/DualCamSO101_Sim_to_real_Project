# Notion 작성 규칙

1. **기본 업로드 위치:** 별도 지정이 없으면 `공부 / Isaac Sim / DualCam SO101` 하위 페이지로 작성한다.
2. **이모티콘 사용 금지:** 페이지 제목, 아이콘(`icon`), 콜아웃, 본문, 표 등 노션 문서 전반에 이모지/이모티콘을 사용하지 않는다. (`icon: "none"` 또는 생략)
3. **중복 금지:** 이전 게시물에 이미 올라간 내용(예: 환경 구축 상세 등)은 중복 서술하지 않고, 직전 이후의 새로운 진행 내용과 결과부터 작성한다.
4. **과장·단정 수치 금지:** 실제 실험·측정으로 나온 수치가 아니면 `100%` 같은 단정적 수치 표현을 쓰지 않는다.
5. **사실 기반 작성:** 모든 수치, 파일 경로, 설정값, 실행 결과는 실제 코드와 실행 로그에서 직접 확인된 내용만 기록한다.
